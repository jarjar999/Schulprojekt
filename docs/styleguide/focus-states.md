# Fokus-States – Classroom-Manager

## Zweck

Fokus-States zeigen sichtbar an, welches interaktive Element aktuell mit der Tastatur ausgewählt ist. Dadurch kann das Registrierungsformular auch ohne Maus bedient werden.

Ein deutlich sichtbarer Fokus ist besonders wichtig für Menschen, die eine Tastatur oder unterstützende Technologien zur Navigation verwenden.

## Betroffene Elemente

Im Registrierungsformular erhalten folgende Elemente einen sichtbaren Fokus-State:

- Eingabefeld für den Vornamen
- Eingabefeld für den Nachnamen
- Eingabefeld für die E-Mail-Adresse
- Auswahlfeld für die Klasse
- Button „Schüler speichern“

## Darstellung

Das aktuell fokussierte Element erhält einen gelben Rahmen mit einer Breite von 3 Pixeln. Der Rahmen wird mit einem Abstand von 3 Pixeln außerhalb des Elements dargestellt.

Dadurch ist gut erkennbar, welches Feld oder welcher Button gerade aktiv ist.
