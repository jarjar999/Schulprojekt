## UI (User Interface)
UI ist die Gestaltung der Benutzeroberfläche eines digitales Produkts.
Beispiel zum Classroom-Manager 
•	Grüner Button „Anwesend“
•	Roter Button „Abwesend“
•	Tabelle mit Schülernamen


## UX (User Experience)
UX bezieht sich auf das Nutzererlebnis, das ein Benutzer beim Nutzen des digitalen Produkts hat.
Beispiele zum Classroom-Manager:
•	Lehrkraft kann die ganze Klasse in unter 30 Sekunden erfassen
•	Der aktuelle Tag ist automatisch ausgewählt
•	Speicherung erfolgt automatisch
